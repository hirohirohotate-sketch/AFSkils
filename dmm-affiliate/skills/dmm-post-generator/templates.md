# DMM Post Templates

実績のある投稿をベースにしたテンプレート。
プレースホルダーは `{変数名}` で表記。値がなければ `未設定` を入れる。

---

## 売れた型

### 単品VRセール型（direct報酬）

実績投稿の構造：

```
【VRセール情報】
{女優名}さんの{作品種別}VR『{商品名}』
今なら{割引感}の大特価！
{規格1}：{通常価格1} ➔ {セール価格1}　{規格2}：{通常価格2} ➔ {セール価格2}

{一言メモ（商品の内容・魅力を感情込めて1〜2文）}
このチャンスをお見逃しなく！
#{女優名（スペースなし）} #VR動画 #FANZA #セール
{URL}
```

ポイント：
- `【VRセール情報】` は毎回使う固定フック。変えない。
- 女優名は `さん` 付き。商品名は `『』` で括る。
- 価格は 8KVR版と通常版の両方を並べる。矢印は `➔`（→ではない）。
- 一言メモは感情を入れる。「〜が可愛すぎます…！」「〜な展開がたまらない」など。
  ただしオーバーな絶賛は避ける。内容の具体的な特徴を一言で。
- 締めは「このチャンスをお見逃しなく！」で統一。
- ハッシュタグに女優名を含める（例: `#石川澪`）。
- URLはハッシュタグの後。

バリエーション（書き出しを変える）：
- 割引率から始める：「今なら半額以下！」「〇%オフ！」
- 作品紹介から始める：「準新作」「独占配信」「8KVR対応」
- 女優名のみ先に出す：「石川澪さん、セール来てる。」

---

### 100円/大型セール型（カテゴリ報酬）

実績投稿の構造：

```
【激アツ】
FANZA動画{対象本数}作品が{セール価格}の神セール開催中！
対象作品{対象本数}本が今だけ全品{セール価格}（税込）！
{期限}限定！

#FANZA #{セール名タグ} #PR #{ジャンルタグ}
{URL}
```

ポイント：
- `【激アツ】` は固定フック。変えない。
- 「神セール」「全品〇〇円」で規模感を出す。
- 対象本数と期限を必ず入れる。本数が多いほど訴求力が上がる。
- ハッシュタグに `#PR` を入れる（カテゴリ報酬はこれを含めると実績がある）。
- `#エロ動画` など直接的なジャンルタグを入れる。
- 本文にURLは入れない。ハッシュタグの後にURLを置く。

バリエーション：
- 本数を強調：「〇本まとめて〇円！」
- 期限を先に出す：「〇/〇まで！ 〇作品が全品〇円」
- ジャンルを絞る：「VR専門セール」「単体作品限定」

## 冒険型

### ランキング型

ランキングデータがある場合のみ使う。なければ「候補」として書く。

```
【今日のVRランキング】
{順位}位：『{商品名}』{女優名}
{セール価格}（通常{通常価格}）期限{期限}

#{女優名} #FANZA #VR動画
{URL}
```

### 比較型

複数商品を並べるとき、または価格差が大きいときに使う。

```
【価格比較メモ】
同じVRでも今日は値段に差がある。

A：『{商品名A}』{通常価格A} ➔ {セール価格A}
B：『{商品名B}』{通常価格B} ➔ {セール価格B}

{一言メモ}
#FANZA #VR動画 #セール
{URL}
```

### 期限煽り型

残り時間が短い（24時間以内）ときに使う。

```
⚠️ 本日{期限}まで！
{女優名}さんの『{商品名}』が{セール価格}。
通常{通常価格}なので見るなら今日。

#{女優名} #FANZA #セール #期間限定
{URL}
```

### ブログ誘導型

複数作品をまとめて紹介したいとき。

```
【{ジャンル}セールまとめ】
今日チェックした中から何本か。

・『{商品名1}』{女優名1} {セール価格1}（{期限1}まで）
・『{商品名2}』{女優名2} {セール価格2}（{期限2}まで）

詳しくはリンクから。
#FANZA #VR動画 #セール
{URL}
```

---

## ハッシュタグルール

- URLの**前**に置く（実績投稿と同じ順序）
- 単品VRセール型：`#{女優名} #VR動画 #FANZA #セール`
- 100円セール型：`#FANZA #100円セール #PR #エロ動画`
- 冒険型：状況に合わせて3〜5個

使えるタグ候補：
```
#FANZA
#DMM
#VR動画
#セール
#100円セール
#期間限定
#エロ動画
#PR
#{女優名}
```
