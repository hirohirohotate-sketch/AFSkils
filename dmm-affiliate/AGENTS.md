# AGENTS.md

このディレクトリでは、DMM/FANZAアフィリエイト投稿のローカル検証運用だけを扱う。

## 方針

- Webアプリ化と自動投稿は後回しにする。
- 目的は投稿量産ではなく、クリックと成約に近い投稿型を見つけること。
- 2週間で約100投稿を手動投稿し、`data/posts.csv`に記録する。
- 投稿文はプラットフォームで止まりにくい表現に寄せる。露骨な成人向け表現は避ける。

## 「投稿文作って」の固定フロー

ユーザーが「投稿文作って」「投稿文を作って」「次の投稿文」などと言った場合、質問や戦略議論に逸れず、以下を順番に実行する。

1. `skills/dmm-post-generator/SKILL.md` を投稿ルールとして使う。
2. SupabaseからセールVR候補を取得して投稿候補を生成する。

```bash
poetry run dmm-affiliate generate-candidates --source supabase --limit 5 --min-discount-percent 30
```

3. `data/post_candidates.csv` を読み、未投稿・セール中・露骨すぎない候補を選ぶ。
4. 新規アカウント運用では、URLあり投稿だけを出さず、普通投稿も混ぜる。
5. 固定テンプレで投稿文だけを出す。原則として余計な分析、長い説明、方針の再確認はしない。
6. 自動投稿はしない。ユーザーが手動投稿する。

新規アカウントの投稿比率:

| 種別 | 比率 | URL |
|---|---:|---|
| 普通のVR雑談・選び方メモ | 50% | なし |
| URLなしセールメモ | 30% | なし |
| アフィリURLあり投稿 | 20% | あり |

最初の7日間は1日3〜4本まで。URLありは1日1本まで。

URLあり固定テンプレ:

```text
【VRセール情報】
{女優名}さんの{作品種別}VR『{短縮タイトル}』
今なら{割引率}OFFの大特価！
通常版：{通常価格}円 ➔ {セール価格}円

{シチュエーション一言}
{期限}なのでこのチャンスをお見逃しなく！

#{女優名} #VR動画 #FANZA #セール
{URL}
```

普通投稿テンプレ:

```text
VR作品って、価格よりも「距離感」が合うかどうかで満足度かなり変わる気がする。
```

```text
8KVRはハマる作品だと没入感が一気に上がるけど、作品選びを外すと通常版でよかったってなる。
```

```text
セールで見るなら、まず500〜900円台から試すのが一番外しにくい。
```

URLなしセールメモ:

```text
今日見た感じ、500〜900円台のVRセールが多め。
いきなり高いのを買うより、この価格帯で相性を見る方がよさそう。
```

投稿候補を選ぶ優先順位:

| 優先 | 条件 |
|---:|---|
| 1 | 未投稿 |
| 2 | `is_discount = true` / `is_vr = true` |
| 3 | `discount_rate >= 30` |
| 4 | 価格帯が偏らない |
| 5 | タイトルを短く言い換えられる |
| 6 | 期限が近い |

1週間検証中はURLあり投稿テンプレを変えない。変えるのは商品だけにする。普通投稿は自然さを出すため文面を少し変えてよい。

## 目標

| 項目 | 数字 |
|---|---:|
| 月目標 | 20,000円 |
| 作業時間 | 1日2時間 |
| 投稿目標 | 1日8本 |
| 月投稿数 | 約240本 |
| 2週間検証 | 約100本 |
| 投稿比率 | 売れた型70% / 冒険型30% |

## 実装物

| 優先 | 実装物 | 内容 |
|---:|---|---|
| 1 | `dmm-post-generator` | 商品情報・セール情報からX投稿案を作る |
| 2 | 売れた型テンプレ | 単品VRセール型、100円/大型セール型 |
| 3 | 冒険型テンプレ | ランキング型、比較型、期限煽り型、ブログ誘導型 |
| 4 | `data/posts.csv` | 投稿URL、型、インプ、クリック、成約、報酬を記録 |
| 5 | `dmm-post-analyzer` | 週1でCSVを読んで、残す型・捨てる型を判断 |

## 判定基準

| 指標 | 判断 |
|---|---|
| 100インプあたり2クリック以上 | 残す |
| 100インプあたり1クリック未満 | 弱い |
| 成約あり | 最優先テンプレ化 |
| インプだけ高くクリックなし | 文章か訴求がズレている |
