# AGENTS.md

このディレクトリでは、DMM/FANZAアフィリエイト投稿のローカル検証運用だけを扱う。

## 方針

- Webアプリ化と自動投稿は後回しにする。
- 目的は投稿量産ではなく、クリックと成約に近い投稿型を見つけること。
- 2週間で約100投稿を手動投稿し、`data/posts.csv`に記録する。
- 投稿文はプラットフォームで止まりにくい表現に寄せる。露骨な成人向け表現は避ける。

## 目標

| 項目 | 数字 |
|---|---:|
| 月目標 | 20,000円 |
| 作業時間 | 1日2時間 |
| 投稿目標 | 1日8本 |
| 月投稿数 | 約240本 |
| 2週間検証 | 約100本 |
| 投稿比率 | 売れた型70% / 冒険型30% |

## 実装物

| 優先 | 実装物 | 内容 |
|---:|---|---|
| 1 | `dmm-post-generator` | 商品情報・セール情報からX投稿案を作る |
| 2 | 売れた型テンプレ | 単品VRセール型、100円/大型セール型 |
| 3 | 冒険型テンプレ | ランキング型、比較型、期限煽り型、ブログ誘導型 |
| 4 | `data/posts.csv` | 投稿URL、型、インプ、クリック、成約、報酬を記録 |
| 5 | `dmm-post-analyzer` | 週1でCSVを読んで、残す型・捨てる型を判断 |

## 判定基準

| 指標 | 判断 |
|---|---|
| 100インプあたり2クリック以上 | 残す |
| 100インプあたり1クリック未満 | 弱い |
| 成約あり | 最優先テンプレ化 |
| インプだけ高くクリックなし | 文章か訴求がズレている |
